# trackr. — Private Workspace & Habit Tracker

## Purpose
trackr. is a personal productivity, life logging, and habit tracking web app designed for focused daily tracking within a clean, distraction-free environment.

## Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript, CSS3
- **Design System**: Custom CSS variables, responsive typography, Dark/Light modes
- **Architecture**: Progressive Web App (PWA) with Service Worker offline capabilities

## About
trackr. provides private, local-first logging for daily routines, goals, and reflections. It emphasizes fast interaction, zero overhead, and smooth transitions tailored for both mobile and desktop screens.
